# Fernweh-Kompass

Expeditionsplaner als installierbare Web-App: Lust, Anreise, Klima, Unterkunft und Crew angeben, Ziele mit Risiken, Saison und Packliste ansehen, 3 Favoriten wählen und gemeinsam in einer Entscheidungsrunde abstimmen.

- Kein Konto, kein eigener Server. Die gemeinsame Abstimmung läuft verschlüsselt über offene Nostr-Relays (NIP-78). Der Schlüssel steckt nur im Einladungslink.
- Live-Daten ohne Schlüssel: Open-Meteo (Orte, Klima, CC BY 4.0), Wikipedia und Wikivoyage (CC BY-SA), Postleitzahlen über Nominatim (© OpenStreetMap-Mitwirkende, ODbL).
- Weltkarte: Natural Earth über world-atlas. Bibliotheken: d3, topojson-client, nostr-tools.
- Reise- und Sicherheitshinweise immer beim Auswärtigen Amt prüfen.

Auf dem Handy: Seite öffnen und „Zum Startbildschirm hinzufügen“ bzw. „App installieren“ wählen.
